BUG-001: Form displays successful validation indicators for empty fields

Website: https://demoqa.com/automation-practice-form

Environment: Windows 11, Microsoft Edge

Description
The Student Registration Form displays green borders and checkmark icons on multiple input fields, including fields that have not been filled in. This creates misleading visual feedback, suggesting that the fields have been successfully validated.

Steps to Reproduce
1. Navigate to https://demoqa.com/automation-practice-form.
2. Enter a valid first name and last name.
3. Select a gender.
4. Enter a valid 10-digit mobile number.
5. Leave the Email, Picture and Current Address fields empty.
6. Observe the validation indicators displayed on the input fields.

Expected Result
Empty optional fields should remain neutral or display a clearly distinguishable optional-field state. Successful validation indicators should not misleadingly suggest that user-entered data has been verified.

Actual Result
Green borders and checkmark icons are displayed on empty fields, including Email, Picture and Current Address.

Impact
Users may incorrectly assume that all fields have been completed and validated, even when some contain no information.
